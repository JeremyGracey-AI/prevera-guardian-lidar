# Demos

| File | What it is |
|---|---|
| [`mobile-app-concept.html`](mobile-app-concept.html) | A clickable mock of the staff mobile app: rooms, alerts, care-team messages, setup. Open it in a browser (it loads React and Babel from unpkg.com). |

**This is a UI concept with fictional data.** Apart from the author's own name on the Profile screen, every name, room, resident, staff member, message and number on its
screens is invented, and the page says so in a banner. It is not connected to the detector in this repository, and
features it shows (gait and mobility trends, fall-risk scores, messaging) are not implemented here. What the detector
actually does and how well it does it is in the [README](../README.md) and [`docs/`](../docs/).
