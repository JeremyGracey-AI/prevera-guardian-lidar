## Clean-data protocol

- **Tape marks** on the floor at 1.5, 2.0, 2.5, 3.0 m straight out from the sensor, plus one at 2 m / 45° to the side. Stay inside 3 m.
- **Empty room first:** restart the detector (`guardian-down` / `guardian-up`) with nobody in view; wait 10 s before anyone enters. Restart again any time the sensor moves.
- **Labels in the bag:** publish a marker at each phase (`enter`, `fall`, `still`, `exit`) so we never guess from timestamps.
  Tool to write in chunk 3: `tools/mark.py` → `std_msgs/String` on `/labels`, recorded with `ros2 bag record /scan /tracks /fall_events /labels`.
- **Trials:** at 2.0 m: sideways ×2, head-toward-sensor ×2; at 3.0 m: sideways ×1; plus 60 s of normal walking (false-alarm baseline). Stay still 15 s each.
- **Record video on a phone** at the same time (for our review only), start with a hand clap in view of both.

## Lessons learned (tonight)

**Sensing / algorithm**
1. **A 2D LIDAR sees one horizontal slice.** At the original height a person on the floor added *zero* points. Verify with
   `scan_sector.py` before any fall test — don't trust the URDF.
2. **Rolling-median backgrounds eat still people** (~2 s at 40 scans). Fixed with foreground hold (PR #1) — keep the regression test.
3. **"Still" can't be per-scan speed at range.** Point density and occlusion move the centroid more than 0.15 m/s between scans.
4. **Synthetic data hid two bugs** (body lying end-on; person in the warmup window). Real bags are the test set now.
5. **Moving the sensor invalidates the background** — always restart the detector after touching the mount.
6. Near-sensor clutter (~1 track/scan within 0.4 m) and tracker jumps (up to 4.6 m/s) inflate L1 events.

**Ops**
7. **Never run two copies of `sllidar_node`** — they fight over `/dev/rplidar` and `/scan` dies silently. `guardian-up.sh` now refuses.
8. **`pkill -f <pattern>` inside `ssh '…'` can kill your own SSH shell** when the pattern appears in the command. Use `pgrep -x` or `'[b]racket'` patterns, and keep `guardian-down.sh` in its own ssh call.
9. **Long jobs on the Jetson must be detached** (`setsid nohup … &` + log) — the Claude↔laptop link dropped ~10 times tonight.
10. **ros2 CLI on the Jetson:** the daemon wedged (`!rclpy.ok()`); use `--no-daemon`, and best-effort QoS for `/scan` subscribers.
11. **Source the workspace before `ros2 bag record`**, or custom topics (`/tracks`, `/fall_events`) are silently skipped.
12. **WSL mirrored networking breaks DDS multicast** → WSL uses `ROS_LOCALHOST_ONLY=1`; the laptop talks to the Jetson via Foxglove/rosbridge/ssh, not DDS.
13. The Jetson's wired and Wi-Fi addresses differ, and the old docs had the Wi-Fi one: use the wired address.
14. **Smart App Control** blocks unsigned native Python wheels (e.g. `foxglove-wizard`) → run such tools in WSL. Don't turn SAC off (can't turn it back on without reinstalling).
15. PowerShell 7 + `ssh-keygen -N '""'` sets a literal `""` passphrase — use `-N ''`.
